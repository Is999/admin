## 1. 查询权限列表

### 请求示例

```http
GET /api/permissions?page=1&pageSize=10&module=system&status=1
```

### 查询参数

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| page | int | 否 | 1 | 页码 |
| pageSize | int | 否 | 10 | 每页数量 |
| module | string | 否 |  | 权限模块 |
| title | string | 否 |  | 权限名称 |
| uuid | string | 否 |  | 权限码 |
| pid | int | 否 |  | 父级权限 ID |
| is_genealogy | int | 否 | 0 | pid 存在时是否按族谱筛选：1 是，0 仅查直接子级 |
| type | int[] | 否 |  | 权限类型 |
| status | int | 否 |  | 状态，1 启用，0 禁用 |

### 响应示例

```json
{
  "status": true,
  "code": 1,
  "message": "查询成功",
  "data": {
    "list": [
      {
        "id": 1,
        "uuid": "admin.list",
        "title": "查询管理员列表",
        "module": "system",
        "pid": 0,
        "type": 2,
        "status": 1,
        "manageable": true,
        "canCreateChild": true
      }
    ],
    "total": 1
  }
}
```

### 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |

| message | string | 否 |  | 消息 |
| data | object | 是 |  | 权限分页数据 |

#### data 内部字段

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| list | array | 是 | [] | 权限列表 |
| total | int | 是 | 0 | 总数 |

#### list[] 内部字段

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| id | int | 是 |  | 权限 ID |
| uuid | string | 是 |  | 权限码 |
| title | string | 是 |  | 权限名称 |
| module | string | 否 |  | 权限模块 |
| pid | int | 是 | 0 | 父级权限 ID |
| type | int | 是 |  | 权限类型 |

## 5. 编辑权限

### 请求示例

```http
PATCH /api/permissions/1001
Content-Type: application/json

{
  "uuid": "admin.list",
  "title": "查询管理员列表",
  "module": "system",
  "pid": 0,
  "type": 2,
  "description": "后台管理员列表接口"
}
```

路由模板：`PATCH /api/permissions/:id`

### 路径参数

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| id | int | 是 |  | 权限 ID |

### 字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| uuid | string | 否 | 保持原值 | 权限码 |
| title | string | 是 |  | 权限名称 |
| module | string | 是 |  | 所属模块；传空字符串表示清空 |
| pid | int | 是 |  | 明确的父级权限 ID；传 `0` 表示移动到顶级 |
| type | int | 是 |  | 权限类型 |
| description | string | 是 |  | 权限说明；传空字符串表示清空 |

编辑接口必须显式提交 `title`、`module`、`pid`、`type` 和 `description`；`uuid` 省略时保持原值。状态只通过 `PATCH /api/permissions/status/:id` 修改；换父级会在同一事务内重建全部子孙权限族谱。

### 响应示例

```json
{
  "status": true,
  "code": 1,
  "message": "更新成功"
}
```

### 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |
| code | int | 是 | 1 | 业务状态码 |
| message | string | 否 |  | 消息 |

## 6. 修改权限状态

### 请求示例

```http
PATCH /api/permissions/status/1001
Content-Type: application/json

{
  "status": 1
}
```

路由模板：`PATCH /api/permissions/status/:id`

### 路径参数

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| id | int | 是 |  | 权限 ID |

### 字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | int | 是 |  | 状态，1 启用，0 禁用 |

禁用权限会级联禁用全部子孙权限；启用权限前要求全部上级权限已启用。重新启用父节点不会自动启用历史子节点，子节点需要按实际授权边界显式启用。

### 响应示例

```json
{
  "status": true,
  "code": 1,
  "message": "状态修改成功"
}
```

### 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |
| code | int | 是 | 1 | 业务状态码 |
| message | string | 否 |  | 消息 |

## 7. 删除权限

### 请求示例

```http
DELETE /api/permissions/1001
```

### 路径参数

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| id | int | 是 |  | 权限 ID |

### 响应示例

```json
{
  "status": true,
  "code": 1,
  "message": "删除成功"
}
```

### 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |
| code | int | 是 | 1 | 业务状态码 |
| message | string | 否 |  | 消息 |

### 高危操作说明

- 权限码 `uuid` 必须唯一，新增或编辑重复权限码时返回业务码 `30002`。
- 删除权限会级联删除全部下级权限。
- 新增或换父级不能挂到禁用权限路径下。
- 新增、编辑和状态变更会失效权限树、启用路由索引和权限 UUID 索引；删除权限还会在事务内记录受影响角色，并在提交后精确失效对应 `role_permission:{roleID}`，避免关系表已删除但角色原始权限缓存仍残留。
- 缓存同步失败时返回 `data.syncPending=true`，数据库变更已经提交，不要重复操作；精确失效任务由后台自动补偿，补偿完成前鉴权返回 HTTP 503。

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |

| site | string | 否 |  | 文档站，只允许 `admin` 或 `api` |
| title | string | 否 |  | 文档标题模糊筛选 |
| path | string | 否 |  | 站内 Markdown 相对路径模糊筛选 |
| status | int | 否 |  | 状态，1 启用，0 禁用 |

### 响应示例

```json
{
  "status": true,
  "code": 1,
  "message": "查询成功",
  "data": {

        "path": "接口文档/后台系统/权限管理接口.md",
```

|------|------|----------|--------|----------|
| data.list | array | 是 | [] | 文档权限列表 |

| data.list[].id | int | 是 |  | 文档权限 ID |

列表优先读取 `doc_permission_list` 共享缓存，和角色授权页、文档导航使用同一份文档权限定义。文档资源本身由 `internal/routealias/docs.go` 与 `internal/database/assets/admin_doc_permission.sql` 同步维护，因此管理接口不提供创建、改路径或删除不存在文档的入口。

## 9. 修改文档权限状态

### 请求示例

```http
PATCH /api/doc-permissions/status/26
Content-Type: application/json

{
  "status": 0
}
```

### 路径与请求字段

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| id | int | 是 |  | 路径中的文档权限 ID |
| status | int | 是 |  | 状态，1 启用，0 禁用 |

### 响应示例

```json
{
  "status": true,
  "code": 1,
  "message": "状态修改成功"
}
```

路由模板：`PATCH /api/doc-permissions/status/:id`

状态变更会失效 `doc_permission_list` 和 `doc_resource_permission_id`。禁用后，该文档从角色授权可用项和文档资源鉴权索引中移除；重新启用后，已有角色关系继续生效。缓存同步失败的处理规则与正常路由权限一致。
