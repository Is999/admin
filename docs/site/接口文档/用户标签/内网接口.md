# 用户标签内网接口

## 1. 适用场景

供受信任内网服务调用。接口免 JWT，但只注册到 `internal_server`，并要求来源 IP、Ops 令牌、HMAC、时间窗口和 Redis nonce 全部通过校验。

所有接口都必须携带以下请求头：

| 字段 | 是否必须 | 说明 |
| --- | --- | --- |
| `X-Ops-Token` | 是 | 匹配 `ops.token` |
| `X-Ops-Timestamp` | 是 | Unix 秒，允许前后 5 分钟偏差 |
| `X-Ops-Nonce` | 是 | 每次请求生成的 16 字节随机数，使用 32 位小写十六进制编码 |
| `X-Ops-Body-SHA256` | 是 | 原始请求体 SHA256 小写十六进制摘要 |
| `X-Ops-Signature` | 是 | 对 `method\nrequestURI\ntimestamp\nnonce\nbodySHA256` 计算 HMAC-SHA256 |

## 2. 内网工作流触发接口

### 接口

```http
POST /internal/user-tags/workflows
```

### 请求示例

```http
POST /internal/user-tags/workflows
Content-Type: application/json

{
  "mode": "targeted",
  "tagTypes": [2, 3],
  "uids": ["10001", "10002"],
  "dryRun": true
}
```

### 说明

- 请求体与 `POST /api/user-tags/workflows` 完全一致。
- 适合 admin 传 `uids + tagTypes` 发起 `targeted` 骨架任务；`uids` 必须使用十进制字符串，避免跨语言大整数精度丢失。

## 3. 内网指定标签重算接口

### 接口

```http
POST /internal/user-tags/recalculations
```

### 请求示例

```http
POST /internal/user-tags/recalculations
Content-Type: application/json

{
  "tag_types": [30, 31],
  "queue": "maintenance",
  "dry_run": true
}
```

### 说明

- 请求体与 `POST /api/user-tags/recalculations` 完全一致。
- 适合内网服务直接发起 `recalculate` 骨架任务。

## 4. 注意事项

- 这两类接口虽然免 JWT，但不是公网接口。
- 公网监听器不注册这些路由；生产跨主机监听还必须使用明确私网 IP 和 mTLS。
- Redis 不可用或 nonce 已使用时失败关闭，不进入任务逻辑。

## 5. 响应字段说明

| 字段 | 类型 | 是否必须 | 默认值 | 字段解释 |
|------|------|----------|--------|----------|
| status | bool | 是 | false | 状态: true 成功, false 失败 |
| code | int | 是 | 1 | 响应状态码 |
| message | string | 否 |  | 消息 |
| data | object | 否 |  | 返回结构与对应公网接口一致 |
